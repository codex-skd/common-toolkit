<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Common Toolkit for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. Same library, same API surface as the 26.2 build &mdash; only the underlying platform differs.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork, not a back-port</strong>: rebuilt from the upstream <a href="https://www.curseforge.com/minecraft/mc-mods/placebo">Placebo</a> 1.21.1 sources (Shadows_of_Fire, MIT), re-applying the Common Toolkit identity and the feature additions from the 26.2 line on top of the 1.21.1 API.</li>
<li><strong>Feature parity with 26.2</strong>: declarative config, dynamic JSON registries with client sync, dynamic tags for those registries, networking helper, gear sets, brewing mixes, creative tab filling, colour/codec utilities.</li>
<li><strong>Patreon cosmetic system</strong>: not ported (as in the 26.2 build).</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Java 21 toolchain, mixin <code>compatibilityLevel</code> <code>JAVA_21</code>.</li>
<li>Logging unified on SLF4J.</li>
<li>Dynamic-tag system (<code>dynreg/tag</code>) ported to the 1.21.1 <code>HolderSet</code> / <code>TagEntry.Lookup</code> API.</li>
<li><code>neoforge.mods.toml</code>: <code>modLoader = "javafml"</code>, <code>loaderVersion = "[1,)"</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>Common Toolkit is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. See the repository's <code>NOTICE.md</code> for full attribution (MIT for Placebo, LGPL-2.1 for the embedded Forge config code).</blockquote>
