<h2>v0.0.0-beta.1 - Initial release</h2>

<p>First public beta of Common Toolkit, a NeoForge library mod providing shared developer utilities for other mods.</p>

<h3>Features</h3>
<ul>
<li><strong>Configuration</strong>: declarative common/client/server config with an in-game config screen.</li>
<li><strong>Dynamic Registries</strong>: JSON-driven, datapack-reloadable registries with automatic client sync.</li>
<li><strong>Networking Helper</strong>: simplified payload registration/handling on top of the NeoForge networking API.</li>
<li><strong>Gear Sets &amp; Brewing Mixes</strong>: weighted, JSON-configurable dynamic registries.</li>
<li><strong>Creative Tab Filling</strong>: declarative registry to inject items into existing creative tabs.</li>
<li><strong>Color &amp; Codec Utilities</strong>: gradient colors and common <code>Codec</code>/<code>StreamCodec</code> helpers.</li>
</ul>
