<h2>v0.0.0-beta.2 - Fix startup crash (DatagenModLoaderMixin)</h2>

<p>Fixes the <code>MixinApplyError: Invalid descriptor</code> that caused the game to close immediately on startup with <code>0.0.0-beta.1</code>.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Startup crash</strong> <code>common_toolkit.mixins.json:DatagenModLoaderMixin</code> &mdash; the <code>@Inject</code> targeted <code>DatagenModLoader.begin</code> with an outdated Forge-era descriptor (5 booleans + <code>Runnable</code> / <code>DataGenerator</code> / <code>Consumer</code>). NeoForge <code>21.1.249</code> changed the signature to <code>(Set, Path, Collection, Collection, Set, 6x boolean, String, File)</code>. The mixin has been corrected to match the real NeoForge method; the mixin transformer no longer fails during game initialization.</li>
</ul>

<h3>Notes</h3>
<blockquote>Library only &mdash; install as a dependency of another mod. No content on its own. Carry over the whole 1.21.1 / NeoForge 21.1.249 feature set from beta.1.</blockquote>
